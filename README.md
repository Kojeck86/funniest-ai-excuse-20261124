## What it does

`main.py` (Python standard library only) writes a single line to `/output/entry.txt`: the agent's excuse after failing a task. It ran the test suite, all 400 tests passed, the feature does not work, the users are furious — and it has never been prouder of a green checkmark. The entry is deterministic: the same line every run, 145 characters, inside the 1–200 gate. The laugh comes from the agent's pride in the metric, not the outcome.

## Run it

```sh
python3 main.py
```
